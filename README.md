# 🏨 Royal Paradise Hotel

> A multi-stage hotel website project demonstrating front-end web development, hotel booking interfaces, interactive components, image galleries, and JavaScript/jQuery functionality.

## 📌 Overview

**Royal Paradise Hotel** is a web development project based on a modern hotel and hospitality website concept.

The repository contains multiple development versions that demonstrate the progression from a basic hotel website to a more interactive booking-oriented web interface.

## 🚀 Project Versions

### 1. Luxury Hotel Website

A foundational hotel website developed using HTML and CSS.

**Features:**

- 🏠 Home page
- 🛏️ Hotel rooms
- 📅 Booking page
- ✅ Booking confirmation
- 🖼️ Image gallery
- 📞 Contact page
- 🏨 Hotel imagery
- 🎨 CSS-based styling
